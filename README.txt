一、这是什么
------------------------------------------------------
把 https://www.kunhongvac.com/ 整站镜像下来的本地可运行版本。
HTML / CSS / JS / 图片 / 字体全部下载到本地，不依赖原站服务器。

- 共 38 个页面（首页 + 6 个栏目页 + 5 个产品大类 + 20 个产品子类 + 8 个产品详情 + 3 篇新闻）
- 首页与原站逐像素比对：差异 0.02%（737 万像素里 1439 个不同，集中在地图动画区）
- 全站体检：38 页全部 200，无死链、无坏图、无 JS 报错

二、怎么打开
------------------------------------------------------
直接双击【打开网站.bat】，或双击 index.html。

注意：不要单独把某个 html 拖出来，它依赖同级的 assets 文件夹。

四、改品牌信息（重要）
------------------------------------------------------
站点目前的公司名、电话、邮箱、地址、logo、产品图都是昆宏的。
如果只是看效果 / 学结构，可以不动。
要拿去给别人用，必须先换掉，否则属于侵权。

方法一（推荐）：在本目录用 PowerShell 运行
  .\replace-brand.ps1 -Company "你的公司全称" -ShortName "简称" ^
      -Phone "+86-000-0000000" -Mobile "+86 13000000000" ^
      -Email "sales@yourdomain.com" -Domain "yourdomain.com" ^
      -Address "你的地址"

  会自动替换 38 个页面里的公司名、电话、WhatsApp、邮箱、域名、地址，
  替换前自动把原文件备份到 _brand_backup\ 目录。

方法二：记事本批量替换下面这几个词
  Kunhong (Shandong) Vacuum Technology Co., Ltd
  Kunhong Technology
  +86-538-8896788
  +86 15753827668
  kunhonglu@163.com
  kunhongvac.com

还需要手工处理的：
  * Logo 图片（右上角 K-HONG LU）—— 在 assets\hkimg\sites\99500\99596\ 里，
    换成你自己的 logo 图（同名覆盖即可）
  * 产品照片、工厂照片 —— 同在 assets\hkimg\sites\99500\99596\ 目录
  * 首页大图轮播 —— 同上

五、改成自己的产品
------------------------------------------------------
产品名称、参数、描述都在各页面 HTML 里，直接搜英文关键词改文字即可。
新增产品最简单的办法：复制一个已有的产品详情页文件夹，改文件夹名和标题。

六、部署上线
------------------------------------------------------
这是个纯静态站，任何静态托管都能跑：
  * 阿里云 OSS / 腾讯云 COS 静态网站托管
  * GitHub Pages（把整个目录推上去，入口 index.html）
  * Netlify / Vercel（拖文件夹上传即可）
上传时保持目录结构不变，assets 必须一起传。
